# Invoice Maker

A simple and modern web-based Invoice Maker for creating professional invoices quickly and easily.

## 🚀 Live Demo

🔗 **Live Demo:** [hetmochi05.github.io/Invoice-Maker](https://hetmochi05.github.io/Invoice-Maker/)

## ✨ Features

- Create professional invoices
- Modern and clean invoice design
- Multiple invoice templates
- Automatic invoice/bill number generation
- Automatic invoice date
- Automatic due date calculation
- Add and manage multiple invoice items
- Calculate subtotal and total amount
- Support for INR currency
- Business logo support
- Logo watermark support
- Custom watermark opacity
- Invoice status support
- Custom accent color
- Responsive design for desktop and mobile devices
- Generate a clean invoice ready for printing or saving

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## 💻 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter your business and customer details.
5. Add invoice items and prices.
6. Customize the invoice template and appearance.
7. Generate or print your invoice.
